# Third-party skills (installed 27 Oct 2026)

From the 30 plugins in @charliehills' reel (De9mZYXCGeB). All MIT licensed; each folder keeps the upstream licence as `LICENSE.upstream`.
Only the skills that fit Vish's work were taken (research, scripting, editing, motion, design, self-review, memory). The rest of each pack is coding tooling.
`ppt-master` and `archify` are large, so they stay out of git: `scripts/install_plugins.sh` fetches them in a new session.
