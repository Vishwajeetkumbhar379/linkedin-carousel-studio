Built 15 Oct 2026 from 12 posts Vish sent (frame-by-frame teardowns in `research/creators/teardown/`, captions and counts
from the public embed pages, `scripts/research/ig_fetch.py`). Use it for every topic, hook, edit and cover.
Rule that never bends: the psychology gets attention, the content has to be true. No fake numbers, no fake results.

What the two monsters share: a tool everyone already uses (Claude), a villain or a loss (wasted tokens, a "murdered"

specific asset behind a one-word comment, and a "takes 3 minutes" effort cap.

## The 9 levers (use 3 or more in every hook)

1. **Loss**: you are wasting something you care about (tokens, money, hours, reach). Loss beats gain.
2. **Villain or death**: "X just murdered Y", "the format that's killing your reach". A fight is more watchable than a tip.
3. **Borrowed giant**: a company, number or person everyone knows (Microsoft, Claude, 850+ creator deals, 100k stars).
4. **Free + effort cap**: "free", "one command", "3 minutes", "no API key". Removes every excuse not to comment.
5. **Specific numbers**: 1,500 to 3,000 tokens a page, 70%, 30 Reels in 30 minutes. Odd, exact numbers read as true.
6. **Named method + count**: "the Desire Hook Method", "HRST", "4 steps". A name makes it feel ownable, a count makes it finite.
7. **Insider secret**: "brands check this first", "Microsoft had this for months". Vish's 850+ deals are his unfair advantage here.
8. **Disbelief pre-empt**: "Yes, seriously." "I didn't edit a single second." Proof inside the artifact.
9. **Open loops**: "but there's one more thing", "the last one is the one nobody uses", step counters, blurred list up front.

## Hook templates (fill with true facts only)

- `Everyone [common habit] is [wasting X], and [giant] had a free fix for [time].`
- `[Tool] just murdered [job / app / platform].` then `It's free, it's [N] [things], and it takes [N] minutes.`
- `I [did result] in [short time] with [tool]. Yes, seriously.`
- `After [Vish's proof], this is the first thing I [check / cut / ask for].`
- `[Skill] isn't talent. It's a [N]-letter formula.` / `It's called the [Named Method].`
- `This [common thing] is okay. This one gets [result].` (show both)
- `I found a way to [big capability] with AI. It's this [free GitHub repo / setting].`
- `Stop [habit]. Do this instead.` / `You're [doing X] wrong, and it's costing you [Y].`
- `There's a new [thing] that's starting to crush on [platform].`

## Visual hooks (first frame and the next 3 s)

- **Cover = the hook as giant type + one face + one metaphor.** @avigrondin: "Claude just MURDERED LinkedIn", the key
  word in a neon box, two app tiles with a heartbeat line where one flatlines, a mono badge "11 SKILLS . FREE".
  @100xengineers: the giant's logo and keynote shot with "Microsoft solves Claude token problem".
- **Show the loss as a meter**: a "Current Session" bar filling, a token counter racing, a price tag.
- **Show the proof as a number climbing**: GitHub stars, views (155M), counts.
- **Phone mockups of real posts** with the power word highlighted (@peter.visuals), floating reel collages for social proof.
- **Cut every ~2.2 s** (@100xengineers: 27 shots in 60 s): talking head, logo animation, stock person, GitHub page, big number, repeat.
- **Captions**: one word at a time; the key word in a colour box (neon green, lamp orange) for the hook line.

## The comment engine

- One keyword, said twice (early re-hook and the end), on screen as a comment bubble, and in the caption's first line.
- The asset must be specific, free and instant: "the GitHub link + full PDF guide", "the setup guide, takes 3 minutes",
  "3,000 hooks with the original reel links". Vague "my guide" gets 10x fewer comments.
- The guide format that works (@aiwithanushka's REA guide): 1 What you are building, 2 Before you start (table: you need,
  why, where), 3 Setup in 3 steps, 4 Prompt templates, 5 What it can do (table), 6 Troubleshooting (table),
  7 Read this twice (limits, legal), 8 Next steps + follow line. Use it for every `guide.md`.
- Delivery: DMs to everyone who comments. Instagram's official API allows a private reply to each comment on your own
  posts, so this can be automated for free (to build next). LinkedIn: Vish sends the link himself or pins it.

## Format mix that matches the data

- 40% "free tool that saves you X" (P1 New Drop): loss + giant + free + one command. Highest comment ceiling.
- 25% "Claude just killed [job]" agent demos (P2 Hire This AI): villain + proof-first demo.
- 20% Brand-side secrets (P3): insider + loss for creators ("you're underpricing", "brands skip you because").
- 15% Named frameworks (P4): "the 4-step [X] method", carousel + reel.
