# engine/style-templates

Provide reusable visual scene templates with design specs, assets, and agent workflow instructions.

- `style-templates/README.md`: Lists available scene templates, usage steps, asset requirements, and how to replace GSAP CDN with local copy.
- `style-templates/dark-graph-paper-template/AGENTS.md`: Provides agent workflow: copy template, follow root guide, lint, preview, inspect, require user authorization. (uses README.md)
- `style-templates/dark-graph-paper-template/CLAUDE.md`: Provides Claude agent steps: copy template, follow root guide, lint, preview, inspect, need user authorization. (uses README.md)
- `style-templates/dark-graph-paper-template/DESIGN.md`: Specifies dark graph paper style: colors, ambient motion, grid visuals, typography guidance, prohibited changes.
- `style-templates/dark-graph-paper-template/hyperframes.json`: JSON: $schema, registry, paths
- `style-templates/dark-graph-paper-template/index.html`: Dark Graph Paper Template
- `style-templates/dark-graph-paper-template/meta.json`: JSON: id, name, createdAt
- `style-templates/dark-graph-paper-template/package.json`: JSON: name, private, type, scripts
- `style-templates/left-glass-popout/AGENTS.md`: Agent instructions: copy left-glass-popout template, follow root guide, lint, preview, inspect, obtain user authorization. (uses README.md)
- `style-templates/left-glass-popout/CLAUDE.md`: Copy template to video project, read README, use HyperFrames, lint, preview, inspect frames, publish after user approval. (uses README.md)
- `style-templates/left-glass-popout/DESIGN.md`: Define glassmorphism style: dark frosted panels, white text, rounded cards, heavy shadow, left panel motion, no face cover.
- `style-templates/left-glass-popout/hyperframes.json`: JSON: $schema, registry, paths
- `style-templates/left-glass-popout/index.html`: Left Glass Popout
- `style-templates/left-glass-popout/meta.json`: JSON: id, name, createdAt, width, height, fps
