# engine/brand

Define brand tokens, colors, layout, and locked carousel visuals for consistent UI styling.

- `brand/identity.md`: Defines token JSON, locked carousel visuals (tinted cards, #7F77DD, borders), fonts, palette merge, regenerated via make tokens. (uses templates.py, tokens.json, content-more.js)
- `brand/tokens.json`: JSON: $schema, version, status, sources, identity, color, type, layout_1080x1350 (uses templates.py, motion.html, sfx.py, voice.md, cover-psychology.md, qa.py)
