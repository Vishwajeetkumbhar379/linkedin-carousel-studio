# engine/templates/video

Generate video templates for motion, reels, shorts, and night scenes.

- `templates/video/fonts.css`: css file
- `templates/video/motion.html`: motion video (uses screen_record.py)
- `templates/video/night.html`: night video
- `templates/video/reels/claude-instagram.html`: html file
- `templates/video/reels/manus-video-editor.html`: html file
- `templates/video/shorts/captions.js`: Captions module: builds groups of up to 3 words, animates 3D flip, positions amber box, updates per time t. (uses shorts.css)
- `templates/video/shorts/gpt-t.html`: html file
- `templates/video/shorts/hit-send.html`: html file
- `templates/video/shorts/shorts.css`: css file
- `templates/video/talking/cover.html`: cover (uses attention-playbook-2026-10-15.md)
- `templates/video/talking/edit-reel.html`: edit reel
- `templates/video/talking/kallaway.html`: reel (uses style-guide-2026-10-14.md)
