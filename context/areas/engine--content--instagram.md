# engine/content/instagram

Organize Instagram content: profile details, weekly post kits, reels, carousels, captions, and scheduling.

- `content/instagram/profile.md`: Specifies Instagram profile name, bios, link, highlights, and pinned posts. (uses brand-profile.md)
- `content/instagram/week-01-post-kit.md`: Describes Week 1 intro reel video, audio, captions, and posting instructions.
- `content/instagram/week-02-post-kit.md`: Defines Week 2 posting kit with carousel A, reel, carousel B, captions, status. (uses 2026-10-week-2.json, brand-profile.md, cover.html)
