# engine/brand/avatar

Create and manage Vish mascot avatars, prompts, and asset manifests for consistent brand representation.

- `brand/avatar/README.md`: Guides fetching Vish 3D avatar v5, saving as brand/avatar/vish-3d.png, using "mascot" or "hero" fields, no endorsement misuse. (uses skin_tone.py, Vish_Mascot_Claude_Guide.md)
- `brand/avatar/pack/Vish_Mascot_Claude_Guide.md`: Provides Claude prompt detailing mascot appearance, pose/gesture mapping, animation limits, and consistency checks for LinkedIn posts. (uses asset_manifest.json)
- `brand/avatar/pack/asset_manifest.json`: JSON: name, version, format, assets, sheets
