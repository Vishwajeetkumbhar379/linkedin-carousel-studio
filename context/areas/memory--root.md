# memory/(root)

Define, store, and enforce content creation policies, pipelines, and LLM access rules for automation.

- `MEMORY.md`: Defines project goal, LLM usage policy, repo structure, environment, and key constraints. (uses shorts-engine.md, TEARDOWN.md, shorts-reference-style.md)
- `content-engine-state.md`: Tracks content engine branch, free-LLM key location, routine triggers, and key access rules. (uses weekly.py)
- `free-llm-helper.md`: Details free-llm-helper package location, provider chain, safeguards, and key environment names.
- `linkedin-pipeline-state.md`: Specifies LinkedIn carousel pipeline repo, build script, theme, and posting approval rules. (uses vish-linkedin-content-preferences.md, theme.css)
- `shorts-engine.md`: Outlines Shorts animation pipeline, voice usage, environment constraints, and research routine. (uses content-engine-state.md, SUMMARY.md, samples.json, top-reels.json, voice.py)
- `shorts-reference-style.md`: Defines target Shorts animation style, key traits, and application guidelines. (uses shorts-engine.md, TEARDOWN.md)
- `vish-linkedin-content-preferences.md`: Sets LinkedIn post style: relatable stance, visual theme, PDF output, one question. (uses linkedin-pipeline-state.md)
