# The 7 Claude Skills install list (for everyone who commented SKILLS)

Claude Code: run each command in your project folder. Claude.ai: download the skill folder from GitHub and upload it under your skills settings.

The order I'd add them in:
1. **Taste Skill**: `npx skills add Leonxlnx/taste-skill` (stops the generic AI look; MIT)
2. **Web Design Guidelines**: `npx skills add vercel-labs/agent-skills` (pick web-design-guidelines; Vercel's UI review)
3. **LinkedIn Skills**: `npx skills add sergebulaev/linkedin-skills` (20 hook formulas, hook extractor, humanizer; MIT)
4. **Social Media Skills**: `npx skills add charlie947/social-media-skills` (hook generator, niche research, content matrix; MIT)
5. **GSAP skills**: `npx skills add greensock/gsap-skills` (official GreenSock skills; GSAP is 100% free incl. plugins)
6. **Motion Design**: `npx skills add LottieFiles/motion-design-skill` (timing, easing, choreography; MIT)
7. **HyperFrames**: `npx skills add heygen-com/hyperframes` (HTML to MP4 motion video, roughly 400 ready-made effects; Apache-2.0). Tip: set `HYPERFRAMES_NO_TELEMETRY=1` if you don't want anonymous usage stats sent.

Then try: "Use the taste skill and redesign my landing page hero", or "Write 6 hooks for a post about my best client result".

Sources: each repo's README and SKILL.md, read 7 Oct 2026.
