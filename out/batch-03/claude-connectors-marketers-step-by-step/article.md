# The best Claude connectors for marketers and creators: step-by-step guide

## Introduction

Claude’s MCP connectors let you bring live data from tools like Google Drive and many others straight into your chat. This removes the need to copy-paste or switch tabs while you draft campaigns, analyse performance or brainstorm ideas.

## How to access the Connectors Directory

Open Claude or Claude Desktop, click Customize then select Connectors. This opens the directory of available MCP servers where you will see both verified and community connectors listed.

## How to add a connector

Type the name of the service you want, for example Google Drive, to find it in the directory. Select the connector and follow the prompts to allow Claude to access the service.

## How to test the connector

After the window closes, check that the connector is active. To test, open a new chat and ask Claude to fetch a recent file from the service, for example ‘Show me the latest proposal in the Marketing folder’. Claude will return the file name and a snippet, proving the connector works.

## How to repeat for other services

Repeat the same steps for other verified connectors you need. Each appears in the directory. You can have multiple services active at once and switch between them easily in chat.

## What I’d do

I start with Google Drive because it holds most of my briefs and assets. I add it, test it, then add other verified connectors to pull campaign performance data and check upcoming deadlines. Once those are working I feel confident to bring in Notion for content planning and Slack for team updates. The whole process takes less than twenty minutes and gives Claude live access to the data I actually use.
