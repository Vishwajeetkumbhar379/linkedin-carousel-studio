# Research notes: YouTube research with Claude (checked 2026-10-08)

## Verified from official pages
- YouTube Help "View video transcripts" https://support.google.com/youtube/answer/15930243 : you can see the full transcript of any video that has captions. In the video description click "Show transcript". Transcript scrolls with video; click a line to jump. Can also show chapters if available. (Opened via curl; WebFetch cannot resolve support.google.com in this sandbox.)
- YouTube Help "Learn how to use Advanced mode for analytics reports" https://support.google.com/youtube/answer/9717005 : Studio > left menu Analytics > under a report click ADVANCED MODE or SEE MORE > adjust report > at top "Export current view" and choose file format. Downloaded reports limited to 500 rows (YouTube Reporting API for more). Groups up to 500 videos. Save up to 50 reports. Note: from July 2026 YouTube is gradually rolling out an updated Studio, so the Analytics page may look different. Filters include geography, subscription status etc. Breakdown: content, traffic source, geography; Metrics selectable.
- YouTube Help "Tips for Advanced Mode on Analytics" https://support.google.com/youtube/answer/16766491 : groups to compare themes/formats/lengths; filters ('content type' for Shorts, 'traffic source'); Add comparison; compare videos across 24 hour, 7 day, 28 day lifespan; "Review data, identify insights, implement learnings".
- YouTube Help Trends tab (Studio > Analytics > Trends; was "Research") https://support.google.com/youtube/answer/11962757 : top searches over past 28 days from audience and saves; content gaps shown for Shorts per help text (search result summary, not opened directly). Treat as: "look for Trends tab in Analytics; layout may differ".
- Claude Help "Enable and use web search" https://support.claude.com/en/articles/10684626-enable-and-use-web-search : with web search on, Claude can fetch and analyse the full content of URLs you give it (articles, blog posts). Toggle under "+" (lower-left of chat) > Web search; "Some website links may not work"; counts toward usage limits; long articles use much more; does NOT mention video or YouTube.
- Claude API docs "Web fetch tool" https://platform.claude.com/docs/en/agents-and-tools/tool-use/web-fetch-tool : retrieves text, HTML and PDF; "does not currently support websites dynamically rendered with JavaScript"; only fetches URLs that appeared in the conversation (user message, search results). Unsupported content types error (only text, HTML, PDF). No mention of YouTube. (Inference only: YouTube is script-heavy, so do not rely on it; test.)
- Claude Help "Uploading files to Claude" https://support.claude.com/en/articles/8241126-uploading-files-to-claude : chat upload types PDF, DOCX, CSV, TXT, HTML, ODT, RTF, EPUB, JSON, XLSX (XLSX needs code execution and file creation on); images JPEG PNG GIF WebP; 500MB per file; up to 20 files per chat; non-PDF docs are text only; no mention of video/audio files; total must fit context window.
- Claude Help "What are Projects" https://support.claude.com/en/articles/9517075-what-are-projects : self-contained workspaces with own chat histories and knowledge base; all plans incl. free (free max five projects); project knowledge + project instructions; on paid plans RAG kicks in when knowledge nears context limits (up to 10x capacity); Team/Enterprise sharing.
- Claude Help "Use connectors to extend Claude's capabilities" https://support.claude.com/en/articles/11176164 : Customize > Connectors; directory connectors for all users; custom remote MCP connectors on Free (one), Pro, Max, Team, Enterprise; Claude inherits your permissions in the source service; Team/Enterprise owner enables first.
- Claude connectors directory docs https://claude.com/docs/connectors/directory : catalogue of MCP servers; contains verified and community connectors; "Verification isn't a security audit"; Customize > Connectors; ranking usage-based.
- Directory page https://claude.com/connectors (fetched 2026-10-08): ~920 connectors listed; visible verified list included Google Drive, Gmail, Notion, Slack etc. No YouTube entry visible among the ~30 shown (page truncated, so cannot rule out). I could NOT confirm an official Anthropic or Google YouTube connector.

## Unverified / secondary only (do not state as fact)
- Third-party vendors (vidIQ, Supermetrics, Windsor.ai, Adzviser, Coupler.io) say they have Claude connectors for YouTube data. Claimed by vendors' own pages, not confirmed in directory by me. Safe wording: "some third-party analytics tools offer connectors; search the directory for YouTube and read who built it".
- Community YouTube MCP servers on GitHub (transcripts via Data API / caption scraping): unofficial; tell readers to use only if they accept the risk, and check YouTube Terms.
- Claim "Anthropic has no native video ingestion": unverified; safe wording: help pages list documents and images, not video.

## Honest conclusion for the guide
1. No verified official YouTube connector. No official statement that Claude opens YouTube links or reads transcripts. Docs say web fetch handles text/HTML/PDF, not JS-rendered pages; help article never mentions video.
2. Reliable route: you copy the transcript from "Show transcript" (YouTube Help), paste or save as .txt; export your own channel data from Studio Advanced mode (Export current view); paste comments from Studio (own channel) or from public videos for your own analysis; add to a Claude Project.
3. Respect copyright: use transcripts of others' videos only for private research and summarising; never republish them. Do not tell readers to scrape.

## Added 2026-10-08 (second pass)
- YouTube Terms of Service https://www.youtube.com/t/terms (effective as of December 15, 2023 version): not allowed to "access, reproduce, download, distribute ... any part of the Service or any Content except (a) as expressly authorized by the Service; or (b) with prior written permission"; also not allowed to "access the Service using any automated means (such as robots, botnets or scrapers)" except public search engines per robots.txt or with YouTube's prior written permission.
- YouTube Help "Explore trends on YouTube" https://support.google.com/youtube/answer/11962757 (opened): Studio > left menu Analytics > top menu Trends tab. Enter a topic or explore trending page; Save a search term. Cards: Top searches (audience + saves, last 28 days), Breakout videos (well-performing content from similar creators), Recent videos, Content gaps for Shorts. Audience interest very low to very high (videos watched over 1,000 times a week, last 28 days). Content gap = viewers can't find enough quality results for a search (none, no exact match, old/low quality). Some insights limited to certain countries, languages, devices. Updated Studio rolling out from July 2026.
- Claude connector verification https://claude.com/docs/connectors/verification (opened): Verified = Anthropic tested tools, not a security audit; Community = third-party, screened not reviewed in depth; Custom = you added it. Developer controls tools and can change them; Anthropic doesn't control how a third-party connector handles your data; review permission scopes.
- vidIQ page returned HTTP 429 (rate limited), so vendor claims of Claude directory listings remain unverified.
- Free accounts: usage limits reset every five hours (web-search help article).
